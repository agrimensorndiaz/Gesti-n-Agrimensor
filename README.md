# Gestión Agrimensor

App para gestionar trabajos de agrimensura: presupuestos, mediciones, cobros y gastos.

Se instala en el celular desde https://agrimensorndiaz.github.io/Gesti-n-Agrimensor/ y funciona sin internet.
Los datos quedan guardados en el celular; las copias de seguridad se guardan en OneDrive desde la app.
